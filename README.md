# Online Shopping Cart System

## Description
A Python mini-application that allows customers to browse available products, manage their shopping cart, and view a checkout summary.

## Features
- Add customer details
- View available products
- Search product by name or code
- Add a product to the cart
- Remove a product from the cart
- View cart contents
- Show customer checkout summary

## Data Structures Used
| Data Structure | Use in Project |
|---|---|
| List | Store available products |
| Dictionary | Store customer details |
| Set | Avoid duplicate products in cart |
| Tuple | Return checkout summary |
| String | Search and format information |

## How to Run
python online_shopping_cart.py
